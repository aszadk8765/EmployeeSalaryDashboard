# Employee Salary Analytics Dashboard

## Description
This dashboard provides insights into employee salary distribution by department, city, and experience using interactive visualizations.

## Features
- KPI cards for average salary and total employees
- Department and city-wise salary analysis
- Experience vs salary trend and scatter plot
- Department × city heatmap
- Geographic salary map

## Tools Used
- Tableau
- Structured salary dataset

## Purpose
Designed for HR analytics, compensation planning, and management reporting.
